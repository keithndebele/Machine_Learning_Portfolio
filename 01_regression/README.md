# Integrated Project: Understanding Crop Yield

## Project Overview

This project applies **Simple Linear Regression and Machine Learning regression techniques** to investigate the factors that influence crop yield in the fictional agricultural region of **Maji Ndogo**.

The project explores how environmental, geographic, soil, and farm management factors relate to **standardised crop yield**. The objective is to use regression analysis to better understand the relationships between these variables and help identify factors that could contribute to improved agricultural productivity and sustainable farming practices.

This project was completed as part of my **Data Science and Machine Learning learning journey** with **ExploreAI Academy**.

## Project Objective

The main objective of this project is to understand the factors that influence **Standard_yield**, the target variable representing the standardised yield expected from a field.

The project uses regression techniques to:

* Explore relationships between variables and crop yield
* Identify potential predictors of standardised crop yield
* Build regression models
* Evaluate model performance
* Interpret the results of the regression analysis

## Dataset Features

The dataset contains several categories of agricultural and environmental information.

### Geographic Features

* **Field_ID** – Unique identifier for each field
* **Elevation** – Elevation of the field above sea level
* **Latitude** – Geographic latitude
* **Longitude** – Geographic longitude
* **Location** – Province where the field is located
* **Slope** – Slope of the land

### Weather Features

* **Rainfall** – Amount of rainfall in millimetres
* **Min_temperature_C** – Average minimum temperature
* **Max_temperature_C** – Average maximum temperature
* **Ave_temps** – Average temperature

### Soil and Crop Features

* **Soil_fertility** – Measure of soil fertility
* **Soil_type** – Type of soil
* **pH** – Soil acidity or alkalinity level

### Farm Management Features

* **Pollution_level** – Level of pollution in the area
* **Plot_size** – Size of the plot
* **Chosen_crop** – Type of crop cultivated
* **Annual_yield** – Total annual yield from the field

### Target Variable

* **Standard_yield** – Standardised crop yield expected from the field
